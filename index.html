PRODUCT PRINCIPLES

Built to be useful, transparent and resilient.

01

Official sources first

Important opportunity information should be traceable to appropriate official sources whenever possible.

02

Local-first architecture

Core interface behavior should remain useful without depending on an external API for every interaction.

03

Graceful failure

Optional analytics, integrations and external services must never become single points of failure for the main experience.

04

Performance matters

PathForage is designed around mobile-first, low-bandwidth usage and efficient browser-side functionality.
